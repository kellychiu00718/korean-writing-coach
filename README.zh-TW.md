# 慢慢寫 천천히 쓰기 · Write It Slowly

給繁體中文使用者的韓文寫作與聽打練習網站。
**永遠先自己思考過後，再讓 AI 教練陪你一步步修正。**

🔗 **網站（測試版）：** https://writeitslowly.com · [English](README.md)

https://github.com/user-attachments/assets/924a139a-79dc-481b-b018-a6168dbf1042

## 動機和目的

最剛開始想打造這個網站的動機純粹是發現，有了 AI 工具之後，我好像越來越仰賴它，不管是翻譯還是改文章，它都會很快速地直接給我一個看似完美的回覆，雖然很有效率，但實際上我並沒有真正的「思考」，當然也就沒有真正的「學會」。於是慢慢寫這個網站的雛形就出現了，希望大家（包含我自己）能在這個網站中重新找回思考的價值以及學習的快樂。

## 功能

| | |
|---|---|
| **句子工坊** | 選一個文法、看中文情境、自己寫出韓文句子。AI 教練分三層回覆：哪裡要改 → 進一步線索 → 參考寫法，文法依照國立國語院的 1–6 級（大致對應韓檢級數）去分配，因此如果句子中出現比該級數還高的單字，會用小字提示在情境下面 |
| **文法地圖** | 國立國語院標準教育課程 1–6 級、336 項文法。只有使用者將文法正確應用到自己寫出來的韓文句子裡，那一格才會亮起來 |
| **聽打練習** | 目前總共有 116 句來自韓劇、音樂、新聞、綜藝的句子，分成 1–6 級。聽力模式（聽完打出來）和打字模式（測打字速度）。漏打、打錯的字會標出來，作答後下方會附上原始出處，讓使用者能夠點進去聽韓國人實際如何發音。 |
| **複習字卡** | 如果有卡住的文法或者句子，可以自行存起來，之後再複習 |
| **我的** | 視覺化使用者的進步幅度 |

測試版限制：句子工坊目前只有 3、4 級（12 課，已請韓文母語者審核通過）；AI 教練有每人每天和全站每天的次數上限。

## 架構重點

架構圖請看 [English README](README.md#architecture)。

- **所有寫入都經過伺服器**：使用者只能讀自己的資料（RLS），不能直接新增或修改；聽打分數由伺服器重新計算。
- **AI 次數記在資料庫**：每次呼叫 AI 前，由資料庫函式一次檢查並扣掉次數（每人＋全站）；失敗的話只能由伺服器退回次數。
- **參考答案留在伺服器**，使用者輸入的句子正確或是答題三次之後才會給。
- **防機器人**：登入（由 Supabase 驗證）和意見回報（由伺服器驗證）都用 Cloudflare Turnstile。
- **內容安全政策（CSP）**：每次請求產生一次性 nonce，所有回應都帶安全標頭。
- **監控**：伺服器出錯寄警告信、每天排程跑一次不公開的健康檢查、外部上線監控。

## 技術

Next.js 15（App Router、TypeScript）· Tailwind CSS 4 · Supabase（Postgres、Auth、RLS）· Anthropic Claude API · Cloudflare Turnstile · Resend · Vercel · Python（Kiwi 斷詞、Supertonic 語音合成）

## 本機開發

```bash
fnm use            # Node 22
npm install
cp .env.example .env.local   # 依檔案裡的說明填值
npm run dev
```

在 Supabase SQL Editor 依序執行 `supabase/` 裡的 SQL（`schema.sql`，再來 `002`–`008`）。
