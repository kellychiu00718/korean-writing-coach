# 慢慢寫 천천히 쓰기 · Write It Slowly

給繁體中文使用者的韓文寫作與聽打練習網站。**先自己想，再讓 AI 陪你改。**

🔗 **網站（測試版）：** https://writeitslowly.com · [English](README.md)

## 為什麼做這個

很多 AI 寫作工具會直接給你一個寫好的句子，看起來很有效率，卻跳過了最能練出實力的那一步：自己把字想出來。慢慢寫的提示是一層一層給的，你自己試過之後才看得到參考答案；文法地圖記錄的是你真的「會用」的文法，不只是「看得懂」。

## 功能

| | |
|---|---|
| **句子工坊** | 選一個文法、看中文情境、自己寫出韓文句子。AI 教練分三層回覆：哪裡要改 → 線索 → 參考寫法，第幾層由伺服器決定。比這課級數高的單字，會用小字提示在情境下面 |
| **文法地圖** | 國立國語院標準教育課程 1–6 級、336 項文法。只有你在自己的句子裡用對了，那一格才會亮 |
| **聽打練習** | 116 句來自韓劇、歌曲、新聞、綜藝的句子，分成 1–6 級。聽力模式（聽完打出來）和打字模式（測打字速度）。漏打、打錯的字會標出來，作答後附上原始出處。不用 AI，不花 AI 費用 |
| **複習字卡** | 卡住的句子會存起來，之後再複習 |
| **我的** | 兩種練習的進步：文法成長、正確率走勢、聽懂的最高級數、打字速度、可以篩選的句子本 |

測試版限制：句子工坊目前只有 3、4 級（12 課，已請韓文母語者審過）；AI 教練有每人每天和全站每天的次數上限。

## 架構重點

架構圖請看 [English README](README.md#architecture)。

- **所有寫入都經過伺服器**：使用者只能讀自己的資料（RLS），不能直接新增或修改；聽打分數由伺服器重新計算。
- **AI 次數記在資料庫**：每次呼叫 AI 前，由資料庫函式一次檢查並扣掉次數（每人＋全站）；失敗的話只能由伺服器退回次數。
- **參考答案留在伺服器**，學習者做到了才給。
- **防機器人**：登入（由 Supabase 驗證）和意見回報（由伺服器驗證）都用 Cloudflare Turnstile。
- **內容安全政策（CSP）**：每次請求產生一次性 nonce，所有回應都帶安全標頭。
- **監控**：伺服器出錯寄警告信、每天排程跑一次不公開的健康檢查、外部上線監控。

## 技術

Next.js 15（App Router、TypeScript）· Tailwind CSS 4 · Supabase（Postgres、Auth、RLS）· Anthropic Claude API · Cloudflare Turnstile · Resend · Vercel · Python（Kiwi 斷詞、Supertonic 語音合成）

## 本機開發

```bash
fnm use            # Node 22
npm install
cp .env.example .env.local   # 依檔案裡的說明填值
npm run dev
```

在 Supabase SQL Editor 依序執行 `supabase/` 裡的 SQL（`schema.sql`，再來 `002`–`008`）。
